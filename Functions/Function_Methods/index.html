Methods Overview

fn.call(thisArg, ...args) Immediate

Invokes function immediately with custom this. Arguments passed comma-separated.

fn.apply(thisArg, [args]) Immediate

Invokes function immediately with custom this. Arguments passed as an array.

fn.bind(thisArg, ...args) Deferred

Returns a new function with pre-bound this and optional preset arguments for later invocation.
