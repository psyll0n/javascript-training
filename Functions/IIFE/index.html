Syntax Variants & Best Practices

(function () { ... })(); Standard

The canonical IIFE syntax. Outer parentheses force the parser into an expression context so the trailing invocation parentheses immediately execute it.

(function () { ... }()); Crockford

Douglas Crockford's style, wrapping both the function and its invocation parentheses inside the grouping operator to make the immediate execution visually explicit.

(() => { ... })(); ES6 Arrow

Modern arrow function syntax. Concise, does not bind its own this or arguments, and executes immediately.

!function () { ... }(); Unary Operator

Prefix operators like !, +, -, or void turn the function into an expression without leading parentheses. Often generated by minifiers.

(function (win, doc) { })(window, document) Parameter Passing

Passes global objects into local parameters. This speeds up variable resolution, allows minifiers to shorten names to single characters, and prevents global namespace collision.

const res = (function () { return val; })(); Return Value

Evaluates complex multi-line logic and assigns only the returned result to a variable, discarding all intermediary scratch variables from memory immediately.
